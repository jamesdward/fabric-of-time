# Transcripts

The conversations with AI models that shaped this project, kept as part of its record. The thesis asks for a traceable process; these show where the ideas came from and who proposed what.

They are stored as exported, unedited. Each file's own header says what it does and doesn't include.

| [`2026-10-13-02-kingston-experiment.md`](2026-10-13-02-kingston-experiment.md) | The conversation with Claude (Opus 5.5) that produced [experiment 01](../experiments/01-kingston-test/). Messages are word for word; work between messages is summarised in square brackets. |
